## Local Preview

No build step needed. Open directly in browser:

```bash
open Portofolio.html
```

## Deploy to GitHub Pages

1. Push to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, `/ (root)`
4. Set `Portofolio.html` as the entry point — rename to `index.html` if needed
